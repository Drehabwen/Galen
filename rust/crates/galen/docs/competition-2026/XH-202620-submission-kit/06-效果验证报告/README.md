# Galen 效果验证报告

本目录汇总 Galen 的可核验效果材料。评审可按下列顺序阅读：

1. `Galen-技术佐证报告.pdf`：Galen Context Engine 技术报告。围绕项目状态驱动的上下文工程架构，说明方法、系统、受控实验与结果。
2. `Galen-自动化验证与可核验材料.pdf`：展示关键功能的自动化测试、执行记录、量化结果和复核入口。
3. `Galen_两轮真实科研任务用户测评与结果核验报告.pdf`：呈现两轮科研任务的任务输入、系统输出、完成结果和人工核验记录。

## 评审关注点

- 是否能够从研究任务与 RehabID 数据进入完整的分析和论文交付链路。
- 系统关键结果是否保留可复核的任务、证据和产物记录。
- 上下文管理、数据处理和工具调用是否具有可执行的验证材料。
