# Galen 用户体验邀请话术

## 微信/群聊版本

你好，我们正在测试一个面向运动康复科研的工作台 Galen，想邀请你帮忙完成一次约 25 分钟的体验。

你不需要提前学习，也不是测试你的专业知识。我们会给你一组脱敏的运动疲劳研究数据，请你完成三个简单任务：

1. 了解当前研究并提出下一步；
2. 查看多时间点数据并判断变化；
3. 生成一个可预览的研究结果 PDF。

我们会记录完成时间、操作体验和你对结果的判断，只用于改进系统和比赛效果验证。不会收集真实患者信息，也不会公开你的姓名。体验结束后只需要告诉我们：哪里有用、哪里难用、哪些结果你不敢直接相信。

如果你愿意参加，请回复一个方便的时间段，以及你的身份类别（例如：运动康复学生、教师、康复师、科研助理）。

## 开始体验前的口头说明

> 你可以随时指出不理解的地方，但请先按自己的理解操作。我们希望看到真实的使用过程，而不是得到一个“正确演示”。如果你同意，我们会保存任务完成截图；录屏需要你单独同意。
