## 三分钟核验路径

1. 打开《Galen-07-其他材料-测试与核验说明.pdf》了解实验设计与结论。
2. 在 PowerShell 中运行 `./run_judge_benchmark.ps1`，重新汇总两套系统的 150 次保存记录。
3. 打开 `verification-output/judge-summary.csv`，核对完成率、工具调用与时延。
4. 进入 `evidence-data/representative-cases/`，抽查任务输入、两套系统轨迹、自动断言与 Galen 实际产物。

默认 Replay 模式不调用模型、不需要 API Key；`-Mode Live` 用于在完整仓库与已配置模型环境中启动 Galen 实时实验。
