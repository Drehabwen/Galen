## 一、范围解读（问题锚定）

- 这是一个**小样本（n=12）重复测量设计**：12 名健康受试者 × 4 个时间点（0/24/48/72 h）。
- 三类变量（HRV、CMJ、RPE）分别代表自主神经、神经肌肉、主观负荷三个层面，属于「多维度恢复监测」范式。
- 关键设计含义：样本量小 → 统计效能有限、个体差异主导；4 个时间点 → 纵向/重复测量模型，而非独立组间比较。
- 术语严格按任务陈述解读：研究的是**运动疲劳后的恢复监测**，未替换为其他干预或人群。

## 二、证据检索结果（按变量归类）

### A. HRV（心率变异性 / 自主神经恢复）

| 证据 | 类型 | 来源 |
|---|---|---|
| 移动设备 HRV 监测运动员训练适应与恢复状态的叙述性综述 | 叙述性综述 | [PMID: 41516438](https://pubmed.ncbi.nlm.nih.gov/41516438/) · [DOI: 10.3390/s26010003](https://doi.org/10.3390/s26010003) |
| 超短期 HRV 指标（静息与运动后）与公认推荐的一致性评估 | 方法学/一致性研究 | [PMID: 25177179](https://pubmed.ncbi.nlm.nih.gov/25177179/) |
| 通过自主心率调节监测训练状态的系统综述与 Meta 分析 | 系统综述 + Meta | [PMID: 26888648](https://pubmed.ncbi.nlm.nih.gov/26888648/) · [DOI: 10.1007/s40279-016-0484-2](https://doi.org/10.1007/s40279-016-0484-2) |
| 跑步类运动心肺适应变化的微创监测方式 | 系统综述 | [PMID: 36332619](https://pubmed.ncbi.nlm.nih.gov/36332619/) · [DOI: 10.1055/a-1925-7468](https://doi.org/10.1055/a-1925-7468) |

| HRV 与主观恢复作为短跑项目运动员表现预测因子 | 观察性预测研究 | [PMID: 41902046](https://pubmed.ncbi.nlm.nih.gov/41902046/) · [DOI: 10.3390/s26061877](https://doi.org/10.3390/s26061877) |
| 欧洲 U18 橄榄球锦标赛对 HRV 的影响 | 观察性研究 | [PMID: 41855375](https://pubmed.ncbi.nlm.nih.gov/41855375/) · [DOI: 10.1519/JSC.0000000000005362](https://doi.org/10.1519/JSC.0000000000005362) |
| 稳态运动对 HRV 功率谱的影响（早期经典） | 机制/生理研究 | [PMID: 2056900](https://pubmed.ncbi.nlm.nih.gov/2056900/) |

**分析关注点（HRV）**
1. **记录时长决定指标可比性**：超短期记录与推荐时长之间的一致性需先验证，[PMID: 25177179](https://pubmed.ncbi.nlm.nih.gov/25177179/) 专门评估了这一点——若采用 1–5 min 短时记录，必须在方法中说明并给出一致性依据。
2. **指标族与方向**：高质量证据（系统综述 + Meta，[PMID: 26888648](https://pubmed.ncbi.nlm.nih.gov/26888648/)）支持用自主心率调节指标追踪训练状态；应明确报告 RMSSD/SDNN/HF 等指标族，而非笼统写「HRV」。
3. **时间点解读需区分静息与运动后**：0 h 为运动后即刻/短期，24–72 h 属恢复窗，两者生理含义不同（[PMID: 42371083](https://pubmed.ncbi.nlm.nih.gov/42371083/)）。
4. **个体内基线是关键**：n=12 下个体差异大，建议个体化基线（自身参照）而非仅组均值比较（[PMID: 41516438](https://pubmed.ncbi.nlm.nih.gov/41516438/)）。

### B. CMJ（反向纵跳 / 神经肌肉疲劳）

| 证据 | 类型 | 来源 |
|---|---|---|
| 神经肌肉疲劳对 CMJ 特征的影响（篮球高强度练习） | 实验/疲劳诱导研究 | [PMID: 37889855](https://pubmed.ncbi.nlm.nih.gov/37889855/) · [DOI: 10.1519/JSC.0000000000004610](https://doi.org/10.1519/JSC.0000000000004610) |
| 重复冲刺对 CMJ 反弹跳表现指标的急性影响 | 急性干预研究 | [PMID: 40267466](https://pubmed.ncbi.nlm.nih.gov/40267466/) · [DOI: 10.1519/JSC.0000000000005102](https://doi.org/10.1519/JSC.0000000000005102) |
| 代谢性（而非机械性）需求运动后的 CMJ 表现：对长期低频力量抑制的敏感性有限 | 实验研究 | [PMID: 40618319](https://pubmed.ncbi.nlm.nih.gov/40618319/) · [DOI: 10.1007/s00421-025-05882-3](https://doi.org/10.1007/s00421-025-05882-3) |
| 等惯性抗阻负荷后力量与功率恢复时程的解离 | 纵向恢复研究 | [PMID: 29466274](https://pubmed.ncbi.nlm.nih.gov/29466274/) · [DOI: 10.1519/JSC.0000000000001821](https://doi.org/10.1519/JSC.0000000000001821) |
| 定义与量化橄榄球项目中的疲劳 | 概念/方法学 | [PMID: 36897849](https://pubmed.ncbi.nlm.nih.gov/36897849/) · [DOI: 10.1371/journal.pone.0282390](https://doi.org/10.1371/journal.pone.0282390) |
| 精英女子手球运动员的神经肌肉疲劳与恢复 | 观察性研究 | [PMID: 16895532](https://pubmed.ncbi.nlm.nih.gov/16895532/) |
| 国际级赛艇运动员跨时区飞行对 CMJ 表现的影响 | 观察性研究 | [PMID: 32947574](https://pubmed.ncbi.nlm.nih.gov/32947574/) · [DOI: 10.1519/JSC.0000000000003762](https://doi.org/10.1519/JSC.0000000000003762) |

**分析关注点（CMJ）**
1. **不要只看跳跃高度**： fatigued 条件下 CMJ 的「特征」（如离心/向心相位、反应力量指数）比单一高度更敏感，[PMID: 37889855](https://pubmed.ncbi.nlm.nih.gov/37889855/) 与 [PMID: 40267466](https://pubmed.ncbi.nlm.nih.gov/40267466/) 均基于派生指标分析。
2. **CMJ 敏感性有边界**：并非所有疲劳类型都反映在 CMJ 上——[PMID: 40618319](https://pubmed.ncbi.nlm.nih.gov/40618319/) 报告其对长期低频力量抑制的敏感性有限，所以「CMJ 未下降」不能直接推断为「未疲劳」，这一点必须写入局限。
3. **力量与功率恢复时程可能解离**：[PMID: 29466274](https://pubmed.ncbi.nlm.nih.gov/29466274/) 显示二者恢复不同步——因此 24/48/72 h 各时间点应分别报告，而非合并为单一「恢复」标签。
4. **测试标准化**：起跳方式、指令、试次数、地面接触时间等需在方法中固定，否则跨时间点变化无法归因于疲劳（[PMID: 36897849](https://pubmed.ncbi.nlm.nih.gov/36897849/)）。

**分析关注点（RPE）**
1. **量表与锚点必须固定**：Borg CR10 / 6–20 / 面部量表不可混用，[PMID: 36227235](https://pubmed.ncbi.nlm.nih.gov/36227235/) 与 [PMID: 38910451](https://pubmed.ncbi.nlm.nih.gov/38910451/) 均强调量表形式影响效度。
2. **区分「单次 RPE」与「session-RPE（sRPE = RPE × 时长）」**：二者分析方法不同，sRPE 是负荷量化指标（[PMID: 31045754](https://pubmed.ncbi.nlm.nih.gov/31045754/)）。
3. **回忆窗口影响效度**：即时 / 每周 / 每月回忆的效度不同（[PMID: 37279792](https://pubmed.ncbi.nlm.nih.gov/37279792/)），本项目 0/24/48/72 h 的测量必须明确是即时还是回忆式报告。
4. **主观—客观交叉验证**：RPE 与心率类客观负荷（[PMID: 31593033](https://pubmed.ncbi.nlm.nih.gov/31593033/)）结合使用时解释力更强，建议与 HRV 联合解读。

## 三、三类变量的联合分析关注点（跨维度）

1. **多维度恢复不等于同步恢复**：HRV（自主神经）、CMJ（神经肌肉）、RPE（主观）恢复时程可能不一致（神经肌肉维度证据见 [PMID: 29466274](https://pubmed.ncbi.nlm.nih.gov/29466274/)；HRV 纵向证据见 [PMID: 42371083](https://pubmed.ncbi.nlm.nih.gov/42371083/)）。分析应逐变量、逐时间点报告，避免合成单一「恢复分数」而掩盖差异。
2. **主观与客观可解离**：RPE 与 HRV 的预测价值在不同人群/项目中表现不同（[PMID: 41902046](https://pubmed.ncbi.nlm.nih.gov/41902046/)），二者应作为互补而非互替指标。
3. **分析与设计匹配（方法匹配原则）**：
   - 12 名受试者 × 4 时间点 = 重复测量设计 → 应使用混合效应模型或重复测量 ANOVA / Friedman（按数据分布），而非独立样本检验。
   - 小样本 → 报告效应量（含置信区间）优先于单纯 p 值；避免多重比较假阳性，需说明校正策略。
4. **批次/来源/时间点/质量状态必须保留**：HRV（设备与记录时长）、CMJ（测试条件）、RPE（量表与回忆窗口）异质测量汇入统一时间轴时，需按 REHABID-FATIGUE-48 保留单位、来源与质量状态；重复、缺失、冲突显式标记。
5. **因果克制**：以上多为观察性或小样本实验证据，可用于「监测与描述」；**不足以**建立干预因果或推广到其他人群/项目。所有结论限定于已检索来源。
