## 仍需负责人完成

1. 报名系统下载、学校盖章并放入 `01-参赛信息`。
2. 部署可访问的 Demo 地址，并写入 `03-作品Demo`。
3. 制作不超过 100 MB 的 `04-作品方案` PPT。
4. 邀请至少 2 名真实目标用户独立试用，完成 `06-效果验证报告/人工评测记录表.md`；每人完成 3 个典型问题，并保存输入、输出、引用链接和 PDF 交付截图。
5. 负责人签署 `02-伦理与安全合规性声明.pdf`。

## 评测记录原则

不把系统断言当成人工判断。人工评阅者应独立检查当前范围遵循、核心事实保留、归档范围隔离和交付可用性，并记录身份、任务用时和逐项评分。

## 交付口径

作品方案、Demo 和效果验证统一围绕一个闭环展开：从 RehabID 导入脱敏队列，完成数据清洗与多时间点分析，经 Galen 生成带可核验来源的研究结果，并交付正式 PDF。演示视频展示真实应用交互；PPT 解释产品、技术、验证和迭代，不用 PPT 代替 Demo。
