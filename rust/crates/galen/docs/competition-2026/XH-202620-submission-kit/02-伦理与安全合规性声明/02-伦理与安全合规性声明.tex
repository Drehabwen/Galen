\section*{一、声明范围}
本声明适用于本团队提交的 Galen 应用系统、Demo、代码、模型调用配置、技术报告、效果验证报告及相关附件。声明中的“作品”包括 Galen Context Engine、RehabID Connector 以及由其生成的科研分析和论文 PDF 交付流程。

\section*{二、数据使用承诺}
\begin{enumerate}[leftmargin=2.4em,itemsep=0.65em]
\item 本团队承诺不使用未经脱敏的真实个人数据，包括但不限于学生、患者、运动员、受试者的姓名、联系方式、身份证件、病历号、精确住址或其他可直接识别个人身份的信息。
\item Demo 与测试材料仅使用去标识化的 RehabID、聚合指标、结构化测试记录或经授权的公开资料。展示截图和视频不呈现可识别个人身份的内容。
\item 如后续接入真实研究队列，本团队将在数据进入系统前完成去标识化、权限控制和用途登记；超出既定研究用途的数据不进入本作品。
\end{enumerate}

\section*{三、学术诚信与生成内容承诺}
\begin{enumerate}[leftmargin=2.4em,itemsep=0.65em]
\item 本团队承诺不使用作品生成伪造的学术数据、虚假文献、虚构实验结果或其他违反学术伦理与科研诚信的内容。
\item 作品生成的研究建议、分析结果和论文草稿均保留数据来源、任务轨迹和生成时间；需要外部证据时提供可核查的权威来源链接。
\item 作品界面、导出文件和视频中对 AI 生成内容设置明显标识；研究者可查看输入数据、处理过程、引用来源和人工复核记录。
\item 作品不以自动生成结果替代研究者的学术判断；正式提交前由团队成员对数据、方法、引用和结论逐项复核。
\end{enumerate}

\section*{四、知识产权承诺}
本团队承诺对所提交的代码、文档、素材和应用系统享有合法使用与提交权，不抄袭他人作品，不提交与已发布产品、系统或平台构成实质雷同的内容；第三方模型、字体、开源库和图片素材均按其许可范围使用并在材料中保留来源说明。

\section*{五、责任确认}
本声明由团队负责人代表全体参赛成员签署。若作品数据、内容生成或知识产权存在违反赛事规则的情形，本团队承担相应责任。
