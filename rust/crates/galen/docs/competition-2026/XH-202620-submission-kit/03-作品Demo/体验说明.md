# Galen Demo 体验说明

## 1. 一句话介绍

Galen 是面向康复科研的数据治理与执行工作台：把分散的病例、评估、设备和文献证据组织为可追踪的研究状态，并由 PI Agent 驱动分析与成果交付。

## 2. 体验者需要准备什么

- Windows 10/11 电脑，或可运行 Rust/Tauri 的开发环境；
- 自己的 DeepSeek API Key；
- 一个空的研究工作区；
- 不需要真实患者数据，Demo 使用脱敏/构造数据。

## 3. 推荐体验问题

```text
请继续当前运动疲劳恢复研究。先告诉我当前项目研究什么、已有哪些数据、下一步最应该做什么。
```

```text
请检查这组 RehabID 的多时间点数据，指出缺失、异常、单位或时间问题，再比较基线、负荷后和恢复期的变化，并说明每个结论依据哪些字段。
```

```text
根据刚才的分析生成论文级结果摘要或 PDF，并列出可以打开验证的文献、数据和分析来源。
```

## 4. 体验结束时应看到的结果

- 当前研究范围和数据来源被正确识别；
- RehabID 队列进入同一纵向时间轴；
- 数据质量问题和指标变化被解释；
- 结果可以回指数据字段、分析任务或文献来源；
- 生成一个可打开、可预览、可继续使用的 PDF 产物。

## 5. 说明

Demo 用于展示科研工作流和数据治理能力，不代表临床诊断结论。体验者应使用脱敏数据，并由自己保管 API Key。
