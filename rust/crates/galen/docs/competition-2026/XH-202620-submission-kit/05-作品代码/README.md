# 05--作品代码

本版已放入 Galen 源码快照、构建说明和技术报告。若最终提交前代码继续变更，重新生成 `source/Galen-source-snapshot.zip` 并记录版本号。建议保留以下结构：

- `source/Galen-source-snapshot.zip`：当前可复现的前端、Tauri 后端和构建配置快照；
- `model/`：模型文件、ServiceID 和调用配置说明；
- `technical-report/`：LaTeX 源码、PDF、截图素材和验证 JSON；
- `reproduce.md`：Windows 环境、依赖、编译和测试命令。

不得把 API 密钥、个人数据或未脱敏日志放入提交包。
