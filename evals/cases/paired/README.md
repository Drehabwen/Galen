# Galen 配对基准任务卡

这组任务卡用于比较“普通对话/普通工具 Agent”和 Galen。每张卡都是一个固定任务，运行时只改变上下文策略或工具编排策略，其他条件保持一致。

## 运行口径

- 上下文组：同一案例分别使用 `--variant full` 与 `--variant fullpack`；`none` 仅作无记忆失败对照。
- 工具组：同一案例、同一工具注册表，分别使用 baseline 与 Galen 工具策略；记录 `tools.calls`、错误、重复调用和产物状态。
- 数据组：使用 `fixtures/paired/common` 中的脱敏固定输入；人工真值写在任务卡对应的 `facts` 与输出要求中。
- 冒烟可重复 1–3 次；正式 `eval compare` 要求每个案例/模型/配置至少重复 5 次。最终报告按配对任务计算成功率、调用数、Token、时延和交付质量。

## 任务编号

- `PCTX01-PCTX05`：上下文保持、修订、范围切换、干扰、文件事实保留。
- `PTOOL01-PTOOL05`：读写、检索、跨文件合并、失败恢复、交付产物。
- `PDATA01-PDATA05`：字段规范、重复/缺失、时间轴、冲突来源、溯源完整性。

任务卡只使用脱敏合成输入，不包含真实个人数据。输出目录由评测器自动创建。
