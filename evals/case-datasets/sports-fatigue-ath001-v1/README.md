# ATH-001 运动疲劳科研演示样例

这是 Galen 参赛 Demo 使用的完全脱敏、可复现样例。数据用于展示“基线—疲劳—恢复”纵向科研流程，不用于临床诊断。

## 文件

- `ATH-001.csv`：可直接导入 Galen 数据体检面板的规范化表格。
- `measurements.json`：进入 RehabID 前的规范化观测值。
- `quality-report.json`：数据体检结果及处理记录。

## 预期闭环

1. 将 `measurements.json` 的观测值写入 RehabID；
2. 以 2026-09-01 为个人基线，比较 2026-09-03 和 2026-09-04；
3. 展示 HRV、CMJ、RPE、疼痛的变化；
4. 将分析结果绑定到研究证据和报告产物。

数值为演示用合成数据，提交材料中必须明确标注这一点。
