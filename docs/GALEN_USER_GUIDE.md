# Galen 产品使用说明

> Galen —— 科研品味驱动的医学科研助手。帮你完成文献检索、证据评估、数据分析、研究方案与论文写作，一条科研任务从头到尾自主推进。

**适用版本**：v0.1.0（Windows 10 / 11 64 位）

---

## 一、安装

1. 双击运行安装包 `Galen_0.1.0_x64-setup.exe`
2. 按提示完成安装，桌面会出现 Galen 图标
3. 首次启动如果提示缺少 WebView2 运行时，会自动联网下载补装，稍等即可

> 需要联网（首次安装、申请密钥、文献检索、AI 对话都需要网络）。

---

## 二、首次启动（三步设置）

启动后进入欢迎向导，按顺序完成：

### 第 1 步：配置 DeepSeek API Key

- 到 [platform.deepseek.com/api_keys](https://platform.deepseek.com/api_keys) 注册并创建 API Key（格式：`sk-` 开头）
- 把 Key 粘贴进输入框，点"保存"
- 保存成功后进入下一步

> 说明：Key 只保存在你自己电脑的 `C:\Users\你的用户名\.galen\models.toml`，不会上传到任何服务器，也不需要在同事之间共享。每位成员用自己的 Key。

### 第 2 步：选择工作区

- 每个科研项目对应一个文件夹（建议用英文路径，如 `D:\AIS-project`）
- 计划、证据、记忆都会自动保存到这个文件夹里

### 第 3 步：开始使用

## 四、核心使用流程（科研任务闭环）

这是 Galen 的核心工作方式，一条任务从"想法"到"成果"自动闭环：

```
输入任务 → AI 生成计划 → 你确认 → 节点自动执行 → 自动回流证据
        → 自动推进下一节点 → 全部完成 → 自动整合成文
```

### 第 1 步：输入科研任务

在主线程用自然语言描述任务，例如：

> 制定「青少年特发性脊柱侧弯（AIS）运动干预系统综述」研究方案并评估证据基础：明确 PICO、给出 PubMed 检索策略、制定纳入排除标准与证据分级方案、检索现有系统综述评估证据强度，输出完整研究方案。

### 第 2 步：确认计划

- AI 会先分析任务并生成一份**科研计划**（画布显示节点）
- 检查计划是否符合你的意图（有没有跑偏、漏步骤）
- 确认后点击"确认计划"，AI 开始执行

> 这是主要的人工介入点：**计划是你可以把关的第一道闸门**。觉得计划不对，直接在对话里让 AI 修改后再确认。

### 第 3 步：节点自动执行

- 每个节点（文献检索、证据提取、数据分析、写作等）由 AI **自主执行**，不需要你逐条操作
- 节点执行中状态显示"运行中"，完成后自动生成结构化摘要（目标/方法/结果/证据/局限）并回流
- 一个节点完成，自动进入下一个，直到全部完成

### 第 4 步：自动整合成文

- 全部节点完成后，AI 自动基于各节点的证据链整合生成最终成果（研究方案/报告/论文初稿）

### 你可以在任何时候介入

- 节点执行中，点进节点可以**手动补充对话**或调整方向
- 节点完成后可以**重新进入**进行修订（状态回到运行中）
- 关键节点（涉及结论、高风险）建议人工检查后再采用

## 五、模型与思考强度

输入框旁边有两个选择器：

**模型选择**

| 模型 | 用途 |
|---|---|
| DeepSeek V4 Pro（默认） | 最强推理，复杂任务 |
| DeepSeek V4 Flash | 快速响应，简单问题 |

**思考强度**

| 档位 | 效果 |
|---|---|
| 思考·关 | 不显示推理过程，最快 |
| 思考·低 / 中 / 高 | 推理深度递增 |

选择会自动记住，下次打开还是你选的档位。

---

## 六、文献检索（PubMed）

- 任务涉及文献时，AI 会自动调用 PubMed 检索
- 结果包含 PMID、标题、作者、期刊、年份、DOI
- 可让 AI 对文献做结构化笔记、按证据等级整理、生成引用

---

## 七、持久化与记忆

- 计划与证据自动保存到工作区根目录的 `plan.json`——**重启应用后计划还在**
- 每次节点回流的关键发现自动追加到 `GALEN.md`（项目记忆）
- 下次任务开始时，AI 会自动读取项目记忆作为上下文

---

## 八、常见问题

| 问题 | 解决办法 |
|---|---|
| 弹出"配置 API Key"向导 | 点顶栏"模型状态"，确认密钥是否已配置（显示掩码如 `sk-b82b…6a7`）；未配置就重新粘贴保存 |
| 检索出错 / PubMed 不可用 | 多为网络波动，重试一次；或换关键词让 AI 再试 |
| 没生成计划 | 任务太简单时不会生成计划，直接回答；复杂任务会生成 |
| 计划/证据丢失 | 检查是否选择了工作区（没选工作区不会持久化） |
| 想换模型 | 输入框旁模型选择器切换 Pro / Flash |
