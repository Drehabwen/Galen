# 教训库

每个文件记录一个具体的调试教训，按编号排序。

## 格式

```markdown
# 简短标题

| 标签 | `tag1` `tag2` |
|------|---------------|
| 日期 | YYYY-MM-DD |
| 文件 | 出问题的文件路径 |

## 现象
## 根因
## 修复
## 教训
```

## 标签

- `bug` — 运行时缺陷
- `streaming` — 流式响应
- `duplication` — 重复数据
- `api-layer` — API 适配层
- `deepseek-v4` — 模型相关
- `frontend` / `backend`

## 规则

- 编号从 001 开始，不跳号
- 每条教训 ≤ 一页，控制在可快速扫描的长度
- 修复部分要有代码 diff
