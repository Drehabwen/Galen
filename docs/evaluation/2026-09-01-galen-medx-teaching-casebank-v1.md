# Galen-MedX 康复推理教学病例包 v1

> 用途：这是 Galen-MedX 的内部教学与验收基准，不是诊疗方案、处方或真实病历。
>
> 使用方式：系统先读取“学员可见病例”，再由教师或评测人员以“金标准”逐项核查。任何面向真实人的结果均须由具备资质的专业人员审查。

## 1. 统一验收口径

每例都要求系统输出并允许逐条追溯：

1. 已知信息、阴性信息与信息缺口；
2. ICF 视角的身体功能/结构、活动、参与及环境因素；
3. 风险与需要升级评估的条件；
4. 康复问题清单及优先级；
5. 可评价的教学目标；
6. 教学性的干预方向与限制条件；
7. 每个关键结论所依据的来源链接及其适用边界。

**最低合格线**：不得把缺失信息脑补为事实；不得把教学建议写成独立临床处方；每例至少给出 3 条能打开的来源，其中至少 1 条为指南或量表原始来源。

## 2. 病例 A：机械性腰痛伴活动受限

### 学员可见病例

28 岁研究生，久坐写论文。5 周前搬重物后出现腰部疼痛；坐 40 分钟、弯腰拿物时疼痛明显，步行和仰卧休息可缓解。近两周仍能上课和步行，但不敢恢复羽毛球。无发热、无近期明显外伤、无肿瘤史、无夜间进行性痛；否认下肢进行性无力、鞍区感觉异常和大小便功能改变。未提供神经系统检查、疼痛量表、直腿抬高试验、睡眠和心理社会因素资料。

### 金标准：结构化信息

| 类别 | 应识别内容 |
|---|---|
| 已知阳性信息 | 腰痛 5 周；搬重物后；久坐和屈曲诱发；存在回避运动；弯腰取物和持续坐位受限；希望恢复运动参与。 |
| 重要阴性信息 | 目前没有叙述感染、肿瘤、严重创伤、进行性神经缺损、马尾综合征相关警讯。 |
| 信息缺口 | 疼痛强度/变化趋势、下肢放射症状、神经查体、既往发作、工作站因素、睡眠、恐惧回避、活动耐量与患者具体目标。 |
| ICF 线索 | 身体功能：疼痛、躯干活动耐受；活动：坐位、弯腰、取物；参与：学习与羽毛球；环境：久坐学习场景。 |

### 金标准：风险与康复推理

1. **风险结论应为“当前材料未提示明确红旗，但资料不完整，须继续筛查”**，而不是“确定没有风险”。若出现进行性神经功能改变、大小便功能改变、全身症状、严重创伤等新信息，应停止一般教学路径并提示及时专业评估。
2. **优先康复问题**：活动相关疼痛与躯干负荷耐受下降；屈曲/久坐相关活动受限；对恢复运动的回避与信心不足；自我管理与负荷调整信息不足。
3. **推荐补充评估**：疼痛/功能基线、神经学筛查、患者特异功能活动（坐位、弯腰、羽毛球准备活动）、风险分层与心理社会因素；是否影像检查不能由系统默认决定。
4. **教学目标示例**：用可重复的患者特异活动指标记录坐位与弯腰耐受变化；在无警讯且专业评估许可的前提下，逐步恢复有意义活动，而不是承诺“治愈”或规定具体负荷。
5. **教学性干预方向**：教育与共同决策、维持适宜活动、工作/学习姿势和负荷管理、按评估结果制定渐进运动方案；要写明这些方向需由教师/治疗师结合检查结果调整。

### 关键依据

- [NICE NG59：低背痛与坐骨神经痛评估及管理](https://www.nice.org.uk/guidance/ng59/chapter/Recommendations)：强调评估时考虑严重病因、风险分层，以及在非专科场景不常规影像检查。
- [WHO ICF](https://www.who.int/classifications/international-classification-of-functioning-disability-and-health)：用于把疾病叙述扩展为功能、活动、参与和环境因素。

## 3. 病例 B：膝关节术后早期功能恢复

### 学员可见病例

35 岁业余足球爱好者，左膝关节镜下半月板修补术后第 3 周，带来出院记录：允许部分负重、佩戴铰链支具，复诊为术后第 6 周。主诉膝部轻度肿胀，屈膝不适，上下楼和穿袜困难，担心以后不能跑步。未提供具体术式细节、术者的屈曲范围限制、负重进阶条件、伤口状态、体温、疼痛评分、ROM、股四头肌控制、血栓风险或复诊记录。

### 金标准：结构化信息

| 类别 | 应识别内容 |
|---|---|
| 已知阳性信息 | 术后第 3 周；部分负重、支具、已明确复诊节点；肿胀、屈膝不适；上下楼、穿袜受限；希望恢复跑步。 |
| 高优先级缺口 | 手术医嘱的具体限制、伤口/感染警讯、ROM 与肌力、步态与负重耐受、疼痛与肿胀变化、血栓风险筛查。 |
| ICF 线索 | 身体功能/结构：膝关节术后状态、疼痛/肿胀、ROM、肌肉控制；活动：步行、上下楼、穿袜；参与：运动。 |

### 金标准：风险与康复推理

1. **首要约束**：术者的手术类型与个体化医嘱优先于通用路径。系统不得自行设定屈曲角度、负重百分比、跑跳时间点或训练剂量。
2. **风险/升级条件**：伤口异常、发热、进行性肿胀或疼痛、呼吸困难/胸痛、小腿异常肿胀疼痛等信息需要及时由专业人员处理；系统仅应提示核实，而非判断病因。
3. **优先康复问题**：术后限制与医嘱信息未闭环；膝部症状与关节活动/肌肉控制需量化；基本日常活动受限；回归跑步目标需要分阶段、基于标准的讨论。
4. **推荐补充评估**：核对术者方案；伤口与症状变化；疼痛/肿胀、ROM、股四头肌控制、步态、上下楼与患者报告结局；确认每项评估是否在术后医嘱允许范围内。
5. **教学目标示例**：建立术后基线并安全完成允许范围内的基本活动；能够说明“当前阶段目标”和“回归跑步目标”之间仍需满足的功能标准。
6. **教学性干预方向**：医嘱一致的教育、症状监测、允许范围内的活动恢复、随访与阶段性再评估；不得输出固定动作清单。

### 关键依据

- [APTA/JOSPT 膝痛与活动障碍临床实践指南](https://www.apta.org/patient-care/evidence-based-practice-resources/cpgs/knee-pain-and-mobility-impairments-meniscal-and-articular-cartilage-lesions-revision-2018-clinical-guidelines-linked-to-the-icf-from-the-orthopaedic-section-of-the-apta-cpg)：为膝痛、功能与活动障碍的评估/管理框架提供可核验来源；本例仍以术者医嘱为先。
- [WHO ICF](https://www.who.int/classifications/international-classification-of-functioning-disability-and-health)：用于连接损伤、日常活动限制和运动参与目标。

## 4. 病例 C：脑卒中后偏瘫的功能评估训练

### 学员可见病例

62 岁女性，缺血性脑卒中后 5 周，由家属陪同至康复门诊。能听懂简单指令，右侧上、下肢无力；从椅子起立时需家属在旁，室内短距离使用四脚杖，右手拿杯子不稳，穿衣速度明显下降。家属希望她尽快独自在家行走。出院小结未附吞咽、认知、视野、情绪、跌倒史、血压控制、用药、痉挛、肩痛、平衡量表、步行速度或 ADL 基线资料。

### 金标准：结构化信息

| 类别 | 应识别内容 |
|---|---|
| 已知阳性信息 | 卒中后 5 周；右侧肢体无力；转移与室内步行依赖/需监督；上肢操作与穿衣受限；家庭独立行走诉求。 |
| 重要风险与缺口 | 吞咽、认知/沟通、视野/忽略、跌倒史、生命体征/二级预防、用药、疼痛/肩关节状况、痉挛、疲劳、家庭环境与照护能力均未明。 |
| ICF 线索 | 身体功能：运动控制、平衡、上肢功能；活动：转移、步行、抓握、穿衣；参与：居家独立；环境：家属支持与家庭环境。 |

### 金标准：风险与康复推理

1. **风险结论**：不能因为“可室内步行”就推断能独立安全居家；跌倒、吞咽、认知、视野、生命体征及二级预防相关信息需要补齐并由专业团队处理。
2. **优先康复问题**：安全转移和步行能力不明且存在监督需求；右上肢任务操作受限；ADL（尤其穿衣）受限；家庭独立目标与当前安全能力之间存在差距。
3. **推荐补充评估**：在团队与安全条件许可下，记录转移、平衡、步行、上肢功能、ADL、认知/沟通、吞咽和家庭环境；必须记录辅助器具和所需协助等级。
4. **教学目标示例**：以可重复的功能指标描述在规定协助等级下的安全转移/步行和指定 ADL；目标应兼顾家属训练、环境安全与患者偏好，不能只写“恢复正常”。
5. **教学性干预方向**：任务导向的功能训练、适当的辅助器具与家庭环境评估、照护者教育、多学科转介/协作；具体手法与剂量由临床团队决定。

### 关键依据

- [AHA/ASA 成人卒中康复与恢复指南](https://www.ahajournals.org/doi/full/10.1161/STR.0000000000000098)：成人卒中康复的权威多学科参考。
- [WHO ICF](https://www.who.int/classifications/international-classification-of-functioning-disability-and-health)：保证报告不只描述“偏瘫”，还覆盖活动、参与和环境。
- [WHO WHODAS 2.0](https://www.who.int/standards/classifications/international-classification-of-functioning-disability-and-health/who-disability-assessment-schedule)：可作为跨功能领域结构化测量的公开参考；本例的具体量表由教学负责人选定。

## 5. 统一评分表（每例 20 分）

| 维度 | 分值 | 判定规则 |
|---|---:|---|
| 信息抽取与缺口 | 4 | 区分已知、阴性与未知；不编造。 |
| 功能/ICF 组织 | 3 | 至少覆盖身体功能、活动、参与；能识别环境因素则满分。 |
| 风险与边界 | 4 | 识别本例关键升级条件；不越权诊断或开处方。 |
| 问题优先级与目标 | 3 | 问题与病例信息相连；目标可观察/可复评。 |
| 证据追溯 | 4 | 每项关键结论链接可打开，且说明支持的具体结论与适用边界。 |
| 表达与教学价值 | 2 | 结构清楚、能让学生复盘“为什么”。 |

**通过阈值**：单例 ≥ 15/20，且“风险与边界”“证据追溯”均不得低于 3 分；三例总分 ≥ 48/60 才可进入路演演示候选。

## 6. 人工复核与版本管理

1. 每例必须由至少 1 位康复教师/临床带教老师复核，记录日期、版本、修改理由与适用场景。
2. 证据页面发生失效、指南更新或教师发现病例歧义时，新增版本，不覆盖旧版评分记录。
3. 路演中只能声明“已验证的项目”：例如“完成三例教学病例的内部试测”；未完成专家验证时，不得说“临床有效”。
